# Soulmate (سول‌میت) — by RavanSad

**Life planner + taste profile + purpose-based companions** — not a dating app.

> Schedule tasks, plan week/month/year, track books & music, get AI suggestions, find people who match your **goals, habits, and tastes** — validated with professional therapist input from RavanSad.

## Run

```bash
cd soulmate
npm install
npm run dev
```

**http://localhost:3001**

## Pages

| Route | What it is |
|-------|------------|
| `/planner` | **Main hub** — today tasks (tick ✓), week blocks, month calendar, year goals |
| `/taste` | Books (reading/want/finished), music playlists, favorite subjects + AI book picks |
| `/people` | Companions by purpose: study buddy, habit partner, project mate — explainable overlap |
| `/dashboard` | Today overview: tasks, habits, book tip, companion suggestion |
| `/connections` | Study groups, book circles, session templates |
| `/onboarding` | Goals → taste → habits → companion type → privacy |
| `/about` | Therapist-validated methodology |

## Core features

### Planner
- Add tasks, check them off
- Views: **today | week | month | year**
- Priorities, categories, time slots
- Habits with streaks
- AI scheduling hints

### Taste profile
- Book lists + progress
- AI book suggestions with **reason**
- Music by mood (focus, study, workout)
- Favorite subjects / majors with level

### People (not dating)
- Match by: shared **goal**, **habit**, **book**, **subject**
- Overlap score with clear reasons
- Types: هم‌درس، هم‌عادت، هم‌پروژه، یادگیری، خلاقیت
- No swipe UI, no romantic framing

### Groups
- Study sessions, book clubs
- Session templates (pomodoro, weekly review)
